# 📖 Glossary

| Term | Meaning | Note |
|---|---|---|
| **ABox / TBox** | Assertional (facts about individuals) vs terminological (schema axioms) parts of a DL knowledge base | [[Description Logics]] |
| **Adamic–Adar** | Link-prediction score weighting shared neighbours by 1/log(degree) | [[Link Prediction Heuristics]] |
| **Bi-temporal** | Tracking both *valid time* (when true in the world) and *transaction time* (when recorded) | [[Agent Memory as Knowledge Graphs]] |
| **Blocking** | Cheap candidate-pair generation in entity resolution | [[Entity Resolution]] |
| **Closed-world assumption (CWA)** | Unknown = false (databases, SHACL) | [[Logic for Knowledge Representation]] |
| **Community report** | LLM summary of a graph community in Microsoft GraphRAG | [[Microsoft GraphRAG]] |
| **Competency question** | Question the ontology must be able to answer; drives requirements | [[Ontology Engineering Methodologies]] |
| **Cypher / openCypher** | Declarative property-graph query language (Neo4j origin) | [[Property Graphs and Cypher]] |
| **Entity linking** | Mapping text mentions to KG entities (e.g., Wikidata QIDs) | [[Information Extraction and Entity Linking]] |
| **Filtered MRR** | Mean reciprocal rank excluding other true triples from the ranking | [[KG Embeddings]] |
| **GQL** | ISO/IEC 39075:2024 standard graph query language | [[Graph Query Languages]] |
| **GraphRAG** | Retrieval-augmented generation using graph structure | [[GraphRAG Overview]] |
| **Graph foundation model (GFM)** | Model pre-trained to transfer across graphs/tasks | [[Graph Foundation Models]] |
| **Heterophily** | Linked nodes tend to differ in labels/features | [[Oversmoothing and Oversquashing]] |
| **IRI** | Internationalized Resource Identifier — global ID in RDF | [[RDF and SPARQL]] |
| **Laplacian** | $L = D - A$; central object of spectral graph theory | [[Spectral Graph Theory]] |
| **Leiden** | Community detection algorithm guaranteeing connected communities | [[Community Detection]] |
| **MCP** | Model Context Protocol — standard for exposing tools/data to LLM agents | [[MCP and Graph Tools]] |
| **Message passing** | GNN paradigm: aggregate neighbour messages, update node state | [[Message Passing and GNNs]] |
| **Modularity** | Quality score of a partition vs. a random null model | [[Community Detection]] |
| **Open-world assumption (OWA)** | Unknown ≠ false (OWL) | [[Logic for Knowledge Representation]] |
| **Over-smoothing** | Node representations converge as depth grows | [[Oversmoothing and Oversquashing]] |
| **Over-squashing** | Exponentially many messages compressed through bottlenecks | [[Oversmoothing and Oversquashing]] |
| **OWL 2 EL / QL / RL** | Tractable OWL profiles | [[OWL 2 and Profiles]] |
| **Personalized PageRank (PPR)** | PageRank with restarts to seed nodes; used by HippoRAG | [[Centrality Measures]] |
| **R2RML / RML** | Mapping languages from relational / heterogeneous data to RDF | [[KG Construction Pipeline]] |
| **SHACL** | W3C Shapes Constraint Language (closed-world validation of RDF) | [[SHACL and ShEx]] |
| **SKOS** | Vocabulary for taxonomies/thesauri | [[SKOS]] |
| **SPARQL** | W3C query language for RDF | [[RDF and SPARQL]] |
| **Unique name assumption (UNA)** | Different names → different individuals (OWL does **not** assume it) | [[OWL 2 and Profiles]] |
| **WL test** | Weisfeiler–Leman colour refinement; upper bound for MPNN expressivity | [[GNN Expressivity and WL]] |
