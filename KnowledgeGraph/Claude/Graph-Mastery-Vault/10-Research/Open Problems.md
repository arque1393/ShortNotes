# Open Research Problems (2025–2026)

> [!tip] Recommended first niche for you
> **1 + 3** (GraphRAG evaluation × temporal agent memory) or **1 + 4** (evaluation × LLM ontology learning) — fits a GenAI/agentic background, modest compute, public code, and both semantic-web and NLP/ML venues.

1. **Science of GraphRAG evaluation** — When do graphs help, why, at what cost? Judge bias, contamination, cost-normalised comparison, sensitivity to KG schema.
   - *Seed Q:* Can we predict from corpus/question features whether GraphRAG will beat hybrid RAG?
2. **Robust GraphRAG over imperfect LLM-built KGs** — retrieval drift, hallucinated edges, online KG repair.
   - *Seed Q:* How does accuracy degrade with controlled noise in extracted triples?
3. **Bi-temporal KGs for agent memory** — invalidation semantics, knowledge updates, forgetting/erasure, sound benchmarks.
   - *Seed Q:* A formal spec + test suite for "as-of" and contradiction behaviour of memory systems.
4. **LLM ontology learning beyond taxonomies** — axiom learning, reasoner-in-the-loop repair, alignment to foundational ontologies (LLMs4OL).
5. **Neuro-symbolic reasoning with guarantees** — faithful paths, ontology-constrained decoding, verifiable text-to-query.
6. **Graph foundation models** — graph "vocabulary", cross-domain transfer, scaling laws, GNN vs LLM backbone, benchmarks of true transfer.
7. **Scalability** — billion-edge training, incremental GraphRAG indexing, linear-cost graph retrieval.
8. **Expressivity vs trainability** — do graph transformers beat well-tuned MPNNs? Over-squashing remedies in practice.
9. **Temporal graph learning evaluation** — negative sampling and batching pitfalls; TKG forecasting.
10. **Relational deep learning** on enterprise databases (RelBench).
11. **Trust & security** — path-based explanations, prompt injection via graph content in MCP tools, privacy.
12. **Multi-agent shared knowledge** — consistency, provenance, conflict resolution on a shared KG blackboard.
